# CV / Personal page

CV website, built to detail experience, projects, and skills.

## Live version

[pxbrandao.github.io](https://pxbrandao.github.io)

## Technologies Used

- **Stack:** [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML), [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS), [Tailwind CSS](https://tailwindcss.com/), [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- **Icons & Fonts:** [Font Awesome](https://fontawesome.com/), [Iconify](https://iconify.design/), [Google Fonts (Raleway)](https://fonts.google.com/specimen/Raleway)
- **Build / Deployment:** [GitHub Pages](https://pages.github.com/)

## Features

- Responsive two-column layout for desktop and mobile
- Multiple themes and color variations
- Interactive toggles for layout, theme, and project details
- Accessibility considerations (ARIA labels, semantic HTML)
